### contradicts-spec (proven violation)

#### Finding 1 (F-149b05c9) — Execution Gas is not fixed per Operation: the three multisig channel Operations are priced as base cost × the channel's live threshold, and a channel-creating ChannelConfig is charged 0 — **confirmed**, medium severity, high confidence

The Overview's Transaction Fees table reads "Execution Gas | Operations | Fixed per Operation", and the sentence before it says each Operation has an associated Execution Gas cost. The code does carry one fixed `OperationGas::GAS_COST` per Operation type, but the ledger does not charge it. It charges `OpGasCalculator::execution_gas(&thresholds)`, which ChannelConfigOp, ChannelWithdrawOp and ChannelTransferOp override to `GAS_COST × threshold`, the threshold being the channel's configuration or transfer threshold read from live ledger state. `Channels` answers 0 for a channel it does not hold. The same Operation is therefore priced differently depending on the state it lands in: a ChannelConfig costs 112 gas on a channel with configuration threshold 2, 280 on threshold 5, and 0 when it creates its channel. The code comment at `core/src/mantle/gas.rs:167-168` states this intent openly ("derived from the Operation and the state it is validated against EXCLUSIVELY"). The change landed 2026-09-09 (commit `471dbfc9e`, "derive Execution Gas from state"), a month before the 2026-10-08 spec snapshot that still says "Fixed per Operation". A second implementation that prices Operations by their fixed cost would compute a different fee, accept or reject different transactions at the balance check, and feed a different block gas total into the execution-market price update. The finding does not establish fund loss or a consensus split within this implementation; it is a divergence between the published Overview and what the code charges. Transfer, SDP, inscription, deposit, leader-claim and PoW-claim Operations are unaffected.

- Locations: `core/src/mantle/gas.rs:159-165` (`ThresholdSource`, the view of channel thresholds), `core/src/mantle/gas.rs:167-173` (`OpGasCalculator::execution_gas(thresholds)`, default `GAS_COST`), `core/src/mantle/ops/channel/config.rs:95-100` (override: `GAS_COST.checked_mul(configuration_threshold)`), `core/src/mantle/ops/channel/withdraw.rs:73-77` and `core/src/mantle/ops/channel/channel_transfer.rs:92-96` (override: `GAS_COST × transfer_threshold`), `core/src/mantle/channel.rs:145-157` (`Channels` returns 0 for an absent channel), `ledger/src/lib.rs:964-968` (the ledger charges the state-dependent result), `ledger/src/lib.rs:497-515` (fee enforcement against balance).
